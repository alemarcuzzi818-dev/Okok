LUNAR MOD - Forge 1.16.5 (36.2.42)

COMO COMPILAR EL .JAR (sin PC, con GitHub):
1. Crea un repositorio en GitHub y sube TODO el contenido de esta carpeta (incluida la carpeta .github).
2. Entra a la pestana "Actions" y espera a que termine "Build mod" (3-6 min).
3. Abre la ejecucion terminada y baja "lunarmod-jar" abajo en Artifacts (viene en .zip, dentro esta el .jar).
4. Pon el .jar en la carpeta mods de tu Forge 1.16.5.

COMO SE JUEGA:
- Rocket (cohete): clic derecho para ir a la Luna y para volver.
- Traje completo de astronauta (4 piezas) para respirar. Sin traje recibes dano.
- El oxigeno baja 1 por segundo (240 max). Recarga con clic derecho en la Estacion de oxigeno.
- Gravedad baja en la Luna.
- Recetas: ver carpeta data/lunarmod/recipes (hierro, vidrio, lana blanca, cohete de fuegos artificiales, redstone).
